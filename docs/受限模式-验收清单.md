## 三、接口层复核（可选，命令行）

```bash
T=$(cat "$APPDATA/MemoryOS/data/token"); B="http://127.0.0.1:8787"
# 全部应为 403
for p in "/api/task" "/api/plans/import" "/api/ingest/custom-sources" "/api/ingest/validate-source"; do
  printf "%-32s %s\n" "$p" "$(curl -s -o /dev/null -w '%{http_code}' -X POST "$B$p?token=$T" -H 'Content-Type: application/json' -d '{}')"
done
# 全部应为 200
for p in "/api/summary" "/api/tasks" "/api/plans" "/api/ingest/sources" "/api/ingest/custom-sources"; do
  printf "%-32s %s\n" "$p" "$(curl -s -o /dev/null -w '%{http_code}' "$B$p?token=$T")"
done
# 应用系统计划（dryRun 预演，不写库）
curl -s -X POST "$B/api/plans/apply?token=$T" -H 'Content-Type: application/json' \
  -d '{"file":"plan-20260911-demo.json","dryRun":true}'
```

> 注：`POST` 空 body 到受限路由应返回 **403**（而非 400）—— 若返回 400，说明 JSON 体本身非法，与限制无关。
