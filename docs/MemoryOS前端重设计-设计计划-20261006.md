## 1. 现状诊断（代码实证，非印象）

| # | 维度 | 实证 | 判定 |
|---|---|---|---|
| D1 | 假字体栈 | `--font-display: 'Space Grotesk'…` 但 index.html / app.js **无任何 @font-face / link / 字体注入** | 字体从未生效，实际渲染落在 Segoe UI / 微软雅黑；「设计感」是空头支票 |
| D2 | 视觉语言 | 浅色米黄纸底 `#FCF9E8` + 玻璃拟态（rgba 半透明卡 + blur）+ 高饱和青 `#22d3ee` + 20px 大圆角大投影 | 玻璃拟态与「本地运维工具」的气质错位；青色霓虹感过强 |
| D3 | 页面同构 | 7 个主导航页（智能体/记忆中心/任务看板/笔记/连接与治理/规则管理/技能同步）共用同一套 `stat-grid` + `glass-card` 模板，仅子 tab 不同 | 页页同构，无任务域差异，无信息层级 |
| D4 | 密度 | stat 大卡片 + 大间距；但业务是僵尸记忆、仲裁队列、连接健康度这类运维监控 | 一屏信息量偏低，与「驾驶舱」诉求相反 |
| D5 | DOM 契约 | app.js 182 处 `innerHTML` 动态渲染；导航绑定全走选择器（`.nav-item[data-route]`、`.subtab[data-view]`、`dataset`） | **class + data-* + id 是安全边界**；DOM 结构层级可以重构，选择器契约不能断 |
| D6 | 已有资产 | 图标已统一 feather 风 SVG；a11y 已整改（全局唯一 h1、aria-label、role）；echarts 懒加载；双主题（data-theme） | 必须保留，不倒退 |
| D7 | 部署边界 | 实证 `memoryos-dashboard-redesign` **不在 app.asar 内**（asar 只有壳层 main.js），由 dist/dashboard.js 直接 serve | 改 UI 文件即时生效，**无需** `node pack-asar.js` |

**单一最大根因**：视觉系统「不真实且不统一」——假字体栈 + 玻璃拟态 + 七页同构布局三者叠加，整套 UI 像模板不像产品；而它承载的其实是高价值运维数据。

## 2. Redesign 四连问

1. **必须保留什么**：7 页信息架构与路由（`data-route`/`data-view` 契约）；app.js 全部选择器契约；a11y 成果；echarts 懒加载；顶栏功能（语义检索 / 写入记忆 / 主题切换 / 准终端 / 设计模式）。
2. **可重构什么**：全部视觉 token（色彩/字体/圆角/阴影/间距）；导航形态（顶栏→侧栏）；每页布局骨架（打破 stat-grid 同构）；玻璃拟态组件语言。
3. **最大根因**：见 §1 末行——假字体栈 + 气质错位 + 同构。
4. **改造强度**：**Layout Restructure + 视觉全做**（中高档）。理由：仅打磨（改 token）解决不了同构根因；全面重做（连信息架构也重排）会动 app.js 渲染层 182 处 innerHTML，回归风险与收益不成比例。

## 3. 审美方向 · 三选一（已按默认推荐 A 展开，可推翻）

| 方向 | 概念 | 调性 | 布局策略 | 适配度 | 风险 |
|---|---|---|---|---|---|
| **A 终端驾驶舱**（推荐） | 本地优先的运维控制台 | 深色优先、高密度、克制、mono 承载数据 | 左侧栏导航 + 紧凑 KPI 条 + 每页定制骨架 | ★★★ 贴合僵尸记忆/仲裁队列/健康度的监控属性 | 中文长文本可读性需照顾 |
| B 轻工作台 | 日常文档工作台 | 浅色优先、暖灰、中等密度、边框分层 | 保留顶栏 + 卡片流 | ★★ 亲和但弱化监控感 | 与现有气质接近，提升有限 |
| C 档案馆隐喻 | 记忆=档案 | 档案卡、时间线、编号系统做视觉锚点 | 双主题、叙事化布局 | ★★ 个性最强、记忆点最高 | 隐喻贯彻 7 页易失控，执行风险高 |

**方向声明（A）**：Design this as a 本地运维型终端驾驶舱 for 单人重度使用者（多 agent 记忆库的管理者）, using a 克制的深色工业风（Linear/Grafana 一脉）language, centered on 真实数据密度与层级秩序.

## 4. 设计系统规格（方向 A · token 级）

### 4.1 色彩
- 深色优先：中性冷灰黑底（收敛现 `#0a0f14` 蓝黑到 zinc/slate 系），**1px 边框分层替代玻璃拟态投影**；浅色主题保留为次等公民（暖白而非米黄）。
- 单一强调色全站锁定（降饱和青或换石墨蓝，原型阶段给视觉锚点定稿），语义六色（success/warning/danger/archived/merged/superseded）保留但统一饱和度纪律。
- 对比度按 WCAG AA 交付（正文 ≥4.5:1）。

### 4.2 字体（根治 D1 假字体栈）
- 权衡：在线 Google Fonts ✕（本地离线应用）；打包中文字体 ✕（体积）。→ **本地打包 woff2（英数）+ 系统中文栈**。
- UI：Inter/系统栈；**全部数字、ID、状态徽标、时间戳走 mono**（JetBrains Mono / Consolas 回退）——这是「驾驶舱感」的核心载体。
- 删掉 Space Grotesk 假引用，或真装 woff2，二选一，不留空头支票。

### 4.3 布局与组件
- 导航：顶栏 → **左侧固定栏**（可折叠；7 项 + 徽标计数），顶部保留轻量状态条（全局检索 + 主题 + 核心心跳）。app.js 是选择器驱动，迁移成本低。
- 密度：stat 大卡 → **一行式紧凑 KPI 条**（mono 数字 + sparkline），列表行高收紧。
- 反同构：记忆中心=列表主导；任务看板=看板列；连接与治理=健康度矩阵；智能体=会话侧栏 + 详情。每页骨架按任务域定制。
- 组件：玻璃拟态 → 实面卡片 + 1px 边框；20px 圆角 → 6–8px；大投影 → 极轻投影 + hover 边框亮起；feather 图标族原样保留。
