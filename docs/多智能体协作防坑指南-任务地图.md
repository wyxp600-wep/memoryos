# 多智能体协作防坑指南 · 任务地图（MemoryOS）

> 2026-09-13 · 配套「任务地图模块集成增强」落地。原则：**状态唯一权威源 = memory.db 任务状态头**，卡片（cards 表）是派生投影；所有跨 agent 写入走 MCP 工具层，前端只做展示与人工操作入口。

## 架构总览

```
┌─ 智能体层（Claude / Codex / ZCode / DSH / …）
│   MCP 工具：task_assign / task_claim / task_done / task_next / task_context
│   约束：zod Schema 参数校验 + 状态机白名单 + 归属校验（禁覆盖）
├─ 状态层（共享权威源）
│   memory.db（SQLite WAL）：memories(type=task, 七态头) + cards(十态投影)
│   + links(依赖/辅助边) + card_events / memory_events(审计流)
└─ 表现层（dashboard 8787）
    任务地图（唯一任务模块）：拖拽 / 画线 / 富右键菜单 / 状态 chips
    同步器：syncTaskCards（记忆→卡片幂等 upsert）+ pushCardToTask（卡片→记忆 事件驱动）
```

## 并发安全三保险（核心约束 2：禁止后完成者覆盖）

1. **状态机白名单**（server.js assertTransition）：done/cancelled 为终态，无出边；pending 不能直接 done。
2. **归属校验**（本次新增，task_done L1001）：in_progress/review 态下，只有 assignee 或实际认领者（[by:]）能完成；越权调用被拒并提示「代办请先 task_claim(as=any) 接管」——接管本身写审计。AGENT 未识别（unknown）时放行保兼容。
3. **卡片 CAS**（/api/cards/:id/status）：expected_from 前置校验，并发改写 → 409「状态前置不符」，不静默覆盖。

实测证据（2026-09-13）：
- agentA 认领 #4134（by:agentA）→ agentB 调 task_done → 拒绝：「#4134 由 dsh/agentA 负责（你是 agentB）：禁止覆盖…」
- 卡片 #68 status CAS：expected_from=wrong_state → 409 非法迁移。

### 受限模式注意
RESTRICTED=1（默认）下：新建卡/连线/位置保存被拦（系统计划统一派发）；右键菜单对应项由前端 RESTRICTED 能力位置灰。开发调试：环境变量 MEMORY_RESTRICTED=0。
