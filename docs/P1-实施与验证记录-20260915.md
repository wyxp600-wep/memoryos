```bash
# 1) 语法

# 2) 离线实例（独立数据目录 + scratch 库，不碰生产库/内核）

MEMORY_DB=.workbuddy/tmp/p1-verify/memory.db \
MEMORY_PORT=8799 MEMORY_TOKEN=p1test node dist/dashboard.js

# 3) 静态缓存 / token 抹除
curl -D- -o /dev/null -H "Accept: text/html" "http://127.0.0.1:8799/?token=p1test"   # 302 + location:/
ET=$(curl -sD- -o /dev/null "$B/app.js?token=$T" | grep -i ^etag | awk '{print $2}')
curl -o /dev/null -w "%{http_code} %{size_download}\n" -H "If-None-Match: $ET" "$B/app.js?token=$T"  # 304 0

# 4) limit 钳制（需 >500 条样本才能区分上限）
curl -s "$B/api/top?token=$T&limit=1000000000" | jq length   # 500

curl -s "$B/api/health?token=$T"                 # analyze/db/queries/vacuum/daemon 五段

# 6) 回归
```

## 五、可复用技术事实（本轮实证）

1. **`node:sqlite` 的 `PRAGMA` 取值**：`PRAGMA page_count` 返回 `{page_count: N}`（`freelist_count` / `auto_vacuum` 同理）→ 取值须 `Object.values(row)[0]`，不能写 `row.page_count` 之外的猜测键名。
2. **给 `node:sqlite` 加计时零侵入**：`db.prepare` 是原型方法，用**实例属性遮蔽**即可拦截；返回 `Proxy` 只包装 `all/get/run`，其余方法 `bind(target)` 透传 → 所有调用方（server/dashboard/daemon/smoke）零改动，且 `openDb()` 一处安装即全覆盖。
3. **本 harness 的 `fs.unlinkSync` 被安全删除 shim 接管**：对 `/tmp` 等路径会抛 `[safe-delete] 操作失败: Unknown`，导致验证脚本非零退出（**不是产品缺陷**）→ 验证脚本不要删临时文件，清理改用 bash `rm`。
4. **`VACUUM INTO` 目标文件必须不存在**，且路径单引号需转义（`''`）；WAL 下严禁复制 `.db`。
5. **`ANALYZE` 经 `db.exec` 执行后**，`sqlite_master` 出现 `sqlite_stat1`（本次 scratch 库 20 行）→ 可作为「是否真的生效」的机读判据。
