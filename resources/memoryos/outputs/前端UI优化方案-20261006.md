### 5.5 ★ 实施中发现并修复的两处自身缺陷（截图/实测抓出，非静态检查可见）

**缺陷 A：注释里的 `</style>` 字面量导致 CSS 全文失效**
- 追加层注释中写了「放在 `</style>` 末尾的原因」，而 HTML 规范下 `<style>` 元素**内部不支持转义**，解析器遇到 `</style` 序列即提前闭合 style 元素 → 其后全部 CSS 变成**页面可见文本**（截图上直接显示成 CSS 源码）。
- **静态检查为何没抓到**：括号平衡 1194/1194 正常、`grep` 计数正常——因为文件字节层面无任何异常，问题只在 HTML 解析语义层。
- **修法**：改写注释文案，消除字面量；复验 `style 块内 </ 序列: 无 ✓`、首个 `</style>` 后紧跟 `</head><body>`。
- **教训**：**只验结构不验渲染会漏判**（对应既有错误模式⑦「只验状态码不验内容」）。

**缺陷 B：窄屏顶栏溢出——旧类名规则落空**
- 既有 ≤768px 规则针对 `.topbar-actions`，但真实顶栏的右侧容器是 **`.global-nav-right`**（`.topbar-actions` 是已废弃布局的遗留类）⇒ 原有 `flex-wrap:wrap` / `display:none` 规则**全部落空**，从未生效过。
- **CDP 探针实测**（新增 `outputs/overflow-probe.mjs`，复用 a11y 走查的 CDP 模式）：

| 视口 | 修复前 body.scrollWidth | 修复后 | 溢出元素 |
|---|---|---|---|
| 500px | **685**（溢出 185px，头号元凶 `.global-nav-right` 宽 414px） | **500** | 0（仅导航横向滚动内容，属预期） |
| 768px | — | 752 | 0 |
| 1440px | — | 1424 | 0 |

- **修法**：改为对真实类名生效（`.global-nav-right` 可换行可压缩、`.global-nav-scroll` 独占一行横向滚动、搜索框窄屏独占一行），保留功能按钮（不再 `display:none`）。

#### G 批 · 加载与空状态统一
