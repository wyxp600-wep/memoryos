## 任务正文

**【前端】右键菜单加「同步到 MCP」按钮**：卡片右键菜单（`data-ctx-group="card"`）新增一项 `data-action="card-push-mcp"`，点击后调用 `POST /api/cards/:id/push-to-task`，把该卡当前状态/标题回写到对应 MCP 任务记忆（`memories` 表 ref），并 toast 反馈结果。

### 【背景】

MCP 域（`memories` type=task，七态）与地图域（`cards`，十态）是两套状态机。第七阶段已做「地图改动自动回写 MCP」的挂接（拖卡／改标题／改状态），但用户要求在右键菜单给一个显式入口，便于人工触发单卡同步。

| 1 | `memoryos-dashboard-redesign/index.html:3946-3954` | 卡片菜单 DOM（`data-ctx-group="card"`），现有 `data-action="card-assign"/"card-unlink"/"card-edit"/"card-detail"/"card-delete"`，在其后追加一个 menu-item，`data-action="card-push-mcp"`，文案「同步到 MCP」 |

### 【实现要点】

- 新函数建议放在 app.js 的卡片动作区：

  ```js
  async function syncToMcp(cardId) {
    const r = await apiPost(`/api/cards/${cardId}/push-to-task`);
    toast(r.ok ? `已同步：${r.from} → ${r.to}` : `同步失败：${r.error}`);
    await refreshCards();
  }
  ```

- 按钮点击后要防重复（in-flight 置灰），失败要能重试。
- **后端已有接口，不要新建**：
  - 单卡：`POST /api/cards/:id/push-to-task` → `{ok, from, to, memory_id}`
  - 全量对账：`POST /api/cards/push-to-tasks` → `{ok, scanned, pushed, skipped, failed}`
- 前端两处副本（app.js / index.html）改动后需执行 `sync_frontend.mjs` 同步到 `resources/` 下的运行副本，否则界面不生效。

